# 🎵 Muzify

## Description

**Muzify** is a modern music streaming web application designed to provide a smooth and enjoyable music listening experience. It allows users to discover songs, search for music, manage playlists, like songs, and control playback through an interactive music player.

The application features a clean dark-themed interface with a home page, search, library, playlists, liked songs, now-playing section, and a persistent music player.
